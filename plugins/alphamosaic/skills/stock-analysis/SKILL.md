name: alphamosaic-stock-analysis
description: Analyze one or more stocks using sourced snapshots and explicit risk boundaries.
---

Call `analyze_stock` for one ticker or `compare_stocks` for a comparison. Preserve source URLs, timestamps, identity checks, missing values, and the provider status. Treat model commentary as research evidence, not market data, and never state an exact return probability unless a validated source explicitly provides one.

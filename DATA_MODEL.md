# Data model and trust boundaries

Explicit `RAW_SPLIT_PRICE_ONLY_V1` adds `DerivedWeeklyClose`, a close-only research input with DERIVED_FEATURE evidence, USD per anchor share, price-only return basis and PIT NOT_APPLICABLE. Qualified parent observation/action metadata remains separately traced. It cannot validate as HistoricalBar or WeeklyBar and never enters execution/marks. Each SignalEvent stores consumed feature rows with bounded daily-row fingerprints and applied split identities; enclosing future snapshot hashes are excluded from those dependencies. Opt-in experiment artifact schema4 requires `weekly_price_features.csv` in the integrity seal, linking every exported row to its signal. Daily/default artifacts stay schema3, and all previous required-file rules remain unchanged.

Model/missing/unknown labels cannot enter observed numerical action or DatedSignal inputs. Fixture and observed evidence cannot be mixed in either direction; strict feature signals need verified availability plus nonempty source/evidence identity. A PIT assertion does not override an unobserved evidence class. Independent cash reconstruction repeats action-evidence qualification rather than trusting execution, and the strategy kernel separately refuses unqualified feature values. Hypotheses and model commentary remain outside financial observations.

Ordinary cash payment accounting adds explicit optional action terms (effective_date_role EX_DATE, dividend_type ORDINARY_CASH, payment_date, cash_amount_basis EX_DATE_SHARES and source_action_id). Their absence in an old dataset is not repaired. Replay accounting schema2 records aware UTC entitlement/payment events and receivable maps in ledger/equity snapshots. The dataset payload schema remains unchanged; new serialized inputs have their own content hashes. Artifact schema3 adds integrity-required dividend_entitlements.csv, dividend_payments.csv and per-session receivables.csv. Old artifact schemas remain readable without rewriting hashes. Missing-field old ReplayConfig records resolve to schema1 legacy semantics; new ExperimentConfig defaults and named presets explicitly select schema2. Daily, weekly and experiment comparison gates include the declared accounting signature.

WeeklySeries/WeeklyDataset and WeeklyBar are separate schemas; no weekly bar masquerades as a daily HistoricalBar. Natural-week OHLC/volume aggregation retains component hashes, source/adjustment/PIT labels and maximum component availability. Incomplete boundary weeks are explicitly excluded; internal gaps or mixed in-asset identity/source/adjustment fail. A known record of an already-effective RAW action prevents qualification even when it was disclosed late. A simulated weekly NAV timestamp is explicitly not provider evidence.

Experiment artifact schema2 adds closed_lots.csv, open_lots.csv, asset_attribution.csv and weekly_equity.csv to the integrity-required outputs. Old schema1 artifacts remain readable under their original required-file rules. ResearchExecutionContext links each supervised attempt to its frozen plan and ordinal without changing strategy parameters. Research plans are immutable hashed rows; execution events form an append-only hash chain with sequence, call/result and final-count validation. This detects ordinary corruption, not a hostile writer able to rewrite both content and hashes.

Core contracts are frozen Pydantic models with forbidden unknown fields and non-finite values. `ReplayDataset` contains instrument-keyed chronological HistoricalBars, verified SecurityIdentity records, CorporateActions, DatedSignals, aware UTC cutoff, mode and explicit historical-universe/action coverage assertions. Replay revalidates nested input even after model_copy.

Each bar records symbol/session/OHLCV, currency, provider/source URL, observation/publication/known/as-of timestamps, adjustment policy, evidence class, license scope, PIT status and provenance. `known_at` is availability, not a synonym for market date. Raw price, split-adjusted price and total-return series remain distinct. Reconstructed downloads cannot silently become certified historical knowledge.

DatasetStore hashes canonical `{schema_version, dataset}` JSON, assigns that SHA256 as dataset_id/version, stages publication into a unique directory and never replaces an existing snapshot with different metadata. A separately hashed manifest records providers, reported source versions or NOT_REPORTED, acquisition/as-of time, identities, adjustment, calendar XNYS, timezone UTC, daily frequency, evidence class, licensing, universe method and quality policy. Capture retains normalized provider responses, not original HTTP bytes. Acquisition errors remain explicit.

Policies: REJECT refuses review flags; QUARANTINE retains evidence but prohibits replay; WARN and ACCEPT_WITH_PROVENANCE retain review flags but cannot override structural invalidity. Duplicate/out-of-order/missing/non-session bars, invalid price/volume, misaligned assets, mixed identity/currency/adjustment, future availability and corporate-action problems fail closed. No anomaly is silently interpolated. Large jumps and mixed sources require explicit review policy. A corrupt manifest is listed CORRUPT, while load still rejects it.

STRICT_PIT requires causal availability and declared complete historical universe/action evidence; real strict data must use raw prices with complete actions. FIXTURE strict tests only validate software mechanics. RECONSTRUCTED_DIAGNOSTIC retains revision/survivorship/adjustment limitations. The current source adapter does not establish complete delisting or historical-membership coverage.

Outputs: SignalEvent → OrderEvent → Fill, optional OrderAdjustment, CashEntry and LedgerEvent snapshots; EquityPoint stores cash, positions, average costs, market values and NAV. Experiment configuration is validated separately from immutable result artifacts. Financial missing values remain null, never fixture estimates or model assertions.
